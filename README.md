# Өткінші өмір – Қымбат сәт

Қазақша әнге арналған кинематографиялық интерактивті веб-клип.

## Мүмкіндіктері
- **Canvas анимациясы:** күн мен түннің алмасуы, таңғы шуақ, күн сәулелері, орақ ай, баяу айналатын жұлдыздар, құйрықты жұлдыздар, жылжыған бұлттар мен жарық тозаңдары.
- **Субтитрлер:** әннің сөздері экран ортасында fade-in / fade-out эффектісімен ретімен шығады.
- **Басқару панелі:** «Бастау / Кідірту», «Қайта бастау», «MP3 жүктеу» және ойнату барысы жолағы.
- **MP3 синхрондау:** жүктелген әннің ұзақтығына қарай мәтін уақыты автоматты бейімделеді, ал жарық әуеннің басс ырғағына жауап береді.
- **Responsive:** телефон мен компьютерге толық бейімделген.

## Іске қосу
`index.html` файлын браузерде ашыңыз (немесе GitHub Pages арқылы жариялаңыз).

Пернелер: `Space` — бастау/кідірту, `R` — қайта бастау, `←/→` (прогресс жолағында) — 5 секундқа жылжу.
